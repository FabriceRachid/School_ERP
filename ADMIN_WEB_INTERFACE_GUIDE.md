# 🎯 **ADMIN WEB INTERFACE - QUICK START GUIDE**

## 🚀 **Getting Started with Admin Setup**

### **Step 1: Access the Admin Setup**
1. Login to admin account
2. Click on **"Account Setup"** in the sidebar
3. You'll see four main tabs:
   - 🎓 **Create Students** - Create student accounts
   - 👨‍👩‍👧‍👦 **Create Parents** - Create parent accounts
   - 🔗 **Link Accounts** - Connect parents to students
   - ✉️ **Generate Invitations** - Send invitation codes

### **Step 2: Complete Workflow Example**

#### **Creating a Student Account**
1. Go to **"Create Students"** tab
2. Fill in student details:
   - First Name: Marie
   - Last Name: Diop
   - Email: marie.diop@school.edu
   - Class: 6ème A (optional)
3. Click **"Create Student Account"**
4. Note the **temporary password** provided

#### **Creating a Parent Account**
1. Go to **"Create Parents"** tab
2. Fill in parent details:
   - First Name: Mamadou
   - Last Name: Diop
   - Email: mamadou.diop@gmail.com
3. Click **"Create Parent Account"**
4. Account is created in **"PENDING"** state

#### **Linking Parent to Student**
1. Go to **"Link Accounts"** tab
2. Select the parent from dropdown
3. Select the student from dropdown
4. Choose relationship type (Father/Mother/Parent/Guardian)
5. Set as **Primary Contact** if applicable
6. Click **"Create Link"**

#### **Generating Invitation**
1. Go to **"Generate Invitations"** tab
2. Find the student-parent pair in the list
3. Click **"Generate Invitation"**
4. Copy the **invitation code** provided
5. Send it to the parent's email

### **Step 3: Parent Activation Process**
The parent will:
1. Open mobile app
2. Select "Parent" registration
3. Enter the invitation code
4. Set their own password
5. Gain access to linked student's data
